# Keys Run (Unreal Engine 5)

Center console fishing in Marathon, Florida Keys, now with online play: log in with a name and a crew code, and everyone in your crew sees each other's boats and wakes live and shares a crew leaderboard.

## Download

Get **KeysRun-Mac.zip** from the [latest release](../../releases/latest).

Needs a Mac with Apple silicon (M1 or newer) and macOS 14 or newer. There's no Windows version yet.

## Install

1. Unzip it and drag **Keys Run** into your Applications folder.
2. Open it. macOS will say it can't check it for malware, because the game isn't signed with a paid Apple developer account. Click **Done** (not Move to Trash).
3. Open **System Settings → Privacy & Security**, scroll down to the message about Keys Run, and click **Open Anyway**. Confirm with your password.

You only have to do this once. (If you're comfortable with Terminal, `xattr -dr com.apple.quarantine "/Applications/Keys Run.app"` does the same thing.)

## Play online with friends

1. On the start screen, press **L**.
2. Type your name, press **Enter**, type your crew's code, press **Enter**.
3. Pick a boat with **A / D** and press **Enter**.

Everyone who types the same crew code is in the same crew. You'll see their boats with name tags, green dots on the chart, a message when someone lands a fish, and a **Crew** tab on the leaderboard (**B**). The game remembers your login; **L** again logs out.

## Controls

| Key | Action |
| --- | --- |
| W / S | throttle / reverse |
| A / D | steer |
| Hold Space | cast; Space strikes when a fish bites |
| R | reel in |
| K / Space | keep / release a landed fish |
| E | weigh in at a marina dock |
| M | chart |
| G | chartplotter and fish finder |
| B | leaderboard |
| L | log in / out of online play |
| H | sea state |
| O | sunset |
| P | radio |
| 1 / V | helm view / first-person fishing view |
